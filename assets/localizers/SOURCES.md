# MRI Image Sources

Default localizers are real MRI slice images from Wikimedia Commons.
Brain uses axial/sagittal/coronal MRI examples; spine uses representative axial/sagittal/coronal MRI examples.
These are demo training images and may not come from one single patient exam for each case.
